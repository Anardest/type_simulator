# Type Simulator

**Type Simulator** — настольное приложение для автоматизированного посимвольного ввода текста с помощью эмуляции нажатий клавиатуры.

Программа предназначена для ввода больших объёмов текста в приложения, которые не поддерживают вставку через буфер обмена или требуют именно имитации физических нажатий клавиш.

Приложение позволяет редактировать текст, загружать его из файлов, настраивать скорость печати и время ожидания перед началом ввода. Поддерживается автоматическое переключение между русской и английской раскладками клавиатуры.

Программа разработана на Python с использованием Tkinter и pynput.

## Возможности

- **Графический интерфейс** — управление всеми функциями приложения через отдельное окно без использования командной строки.
- **Редактирование текста** — ввод, вставка и изменение текста непосредственно в приложении.
- **Загрузка файлов** — импорт содержимого текстовых файлов формата `.txt`.
- **Автоматическое переключение раскладки** — определение требуемого языка и переключение между русской и английской раскладками.
- **Настройка скорости печати** — возможность задать задержку между вводимыми символами.
- **Настройка времени ожидания** — возможность переключиться на целевое приложение перед началом печати.
- **Управление процессом** — запуск и остановка эмуляции ввода.
- **Отображение состояния** — обратный отсчёт до начала печати, текущий статус и количество введённых символов.
- **Работа в отдельном потоке** — выполнение печати не блокирует графический интерфейс.

### Назначение файлов

**main.py**

Точка входа приложения. Создаёт главное окно Tkinter, инициализирует класс `KeyboardTyperApp` и запускает основной цикл обработки событий.

**app.py**

Основной модуль графического интерфейса. Отвечает за:
- создание элементов интерфейса;
- загрузку и редактирование текста;
- обработку пользовательских действий;
- настройку параметров печати;
- запуск и остановку рабочего потока;
- отображение статуса и прогресса выполнения.

**typing_engine.py**

Модуль эмуляции клавиатуры. Содержит функции:
- `detect_current_layout()` — определение текущей раскладки клавиатуры;
- `toggle_layout()` — переключение раскладки;
- `is_russian()` — проверка принадлежности символа к русскому алфавиту;
- `press_key()` — нажатие и отпускание клавиши;
- `press_dot()` — отдельная обработка точки;
- `type_text()` — посимвольный ввод текста с заданной задержкой и поддержкой остановки.

**config.py**

Централизованное хранение настроек по умолчанию: задержки, времени ожидания и размеров главного окна.

**requirements.txt**

Список внешних библиотек, необходимых для работы приложения.

## Требования

- Операционная система: Windows 10 или Windows 11.
- Python версии 3.9 или выше.
- Установленный pip.
- Доступ к интернету для установки зависимостей.

Tkinter входит в стандартную поставку Python для Windows и отдельно через pip не устанавливается.

**Примечание:** текущая реализация определения раскладки использует Windows API (`ctypes.WinDLL`), поэтому приложение рассчитано на Windows. Несмотря на кроссплатформенность pynput, без адаптации модуля определения раскладки запуск на Linux и macOS не поддерживается.

## Установка и настройка окружения

Для разработки рекомендуется использовать виртуальное окружение Python. Это позволяет изолировать зависимости проекта от других установленных библиотек.

### Клонирование проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/Anardest/type_simulator.git
```

Перейдите в папку проекта:

```bash
cd KeyboardTyper
```

Если проект уже находится на компьютере, достаточно открыть его папку в VS Code.

### Создание виртуального окружения

В корневой папке проекта выполните:

```bash
python -m venv env
```

Будет создана папка `env`, содержащая изолированную среду Python.

### Активация виртуального окружения

**Windows PowerShell:**

```powershell
.\env\Scripts\Activate.ps1
```

**Windows CMD:**

```cmd
env\Scripts\activate.bat
```

После активации в начале строки терминала должно появиться обозначение `(env)`.

### Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

В текущей версии основная внешняя зависимость:

```text
pynput
```

Tkinter и остальные используемые модули относятся к стандартной библиотеке Python.

## Использование приложения

### Работа с текстом

В главном окне приложения доступно большое текстовое поле.

Поддерживаются следующие действия:

- Ввод текста непосредственно с клавиатуры.
- Вставка текста из буфера обмена.
- Редактирование уже введённого текста.
- Загрузка содержимого текстового файла через кнопку **«Загрузить из файла»**.
- Очистка текстового поля через кнопку **«Очистить текст»**.

При загрузке файла программа использует кодировку UTF-8 с поддержкой UTF-8 BOM.

### Настройки печати

В приложении доступны два основных параметра.

| Параметр | Описание | Значение по умолчанию |
|---|---|---|
| Задержка между символами | Интервал между вводимыми символами в секундах | 0.02 |
| Ожидание перед печатью | Время для переключения на целевое окно | 5 секунд |

**Примеры настройки скорости:**

| Задержка | Описание |
|---|---|
| 0 | Максимально быстрый ввод без дополнительной задержки |
| 0.005 | Очень быстрый ввод |
| 0.01 | Быстрый ввод |
| 0.02 | Стандартная скорость |
| 0.05 | Более медленный и размеренный ввод |
| 0.1 | Медленный ввод |

Задержка указывается в секундах и может быть дробным числом. Допускается использование точки или запятой в качестве десятичного разделителя.

### Запуск и остановка печати

Для запуска печати:

1. Введите текст или загрузите его из файла.
2. Укажите необходимую задержку между символами.
3. Укажите время ожидания перед началом печати.
4. Нажмите кнопку **«Начать печать»**.
5. В течение установленного времени переключитесь на целевое приложение и установите курсор в нужное поле ввода.
6. После завершения обратного отсчёта программа начнёт посимвольный ввод текста.

Для досрочного завершения нажмите кнопку **«Остановить»**.

Во время выполнения печати:
- кнопка запуска блокируется;
- кнопка остановки становится доступной;
- интерфейс продолжает реагировать на действия пользователя;
- отображается количество введённых символов.

После завершения или остановки программа возвращается в состояние готовности к следующему запуску.

## Архитектура приложения

Приложение разделено на несколько независимых модулей, каждый из которых отвечает за свою область функциональности.

Основные компоненты взаимодействуют следующим образом:

```text
              main.py
                 |
                 v
                app.py
                 |
        +--------+---------+
        |                  |
        v                  v
   config.py        threading.Thread
                           |
                           v
                     typing_engine.py
                           |
                           v
                    pynput.keyboard
                           |
                           v
                   Операционная система
```

**Основные принципы организации кода:**

1. Разделение интерфейса и логики печати. Модуль `typing_engine.py` не зависит от Tkinter и может использоваться отдельно от графического приложения.
2. Асинхронное выполнение печати. Для предотвращения зависания окна используется отдельный поток `threading.Thread`.
3. Передача сообщений между потоками. Для безопасной передачи статуса и прогресса применяется `queue.Queue`. Изменения элементов интерфейса выполняются основным потоком Tkinter.
4. Централизация настроек. Параметры по умолчанию вынесены в отдельный файл `config.py`.

Такое разделение упрощает сопровождение проекта и позволяет в дальнейшем расширять функциональность или заменять графический интерфейс без необходимости переписывать движок печати.

## Самостоятельная сборка EXE

Для создания самостоятельного исполняемого файла используется PyInstaller.

Это позволяет запускать приложение на Windows без ручной активации виртуального окружения и установки Python на компьютере пользователя.

### Установка PyInstaller

Активируйте виртуальное окружение:

```powershell
.\env\Scripts\Activate.ps1
```

Установите PyInstaller:

```bash
pip install pyinstaller
```

PyInstaller является инструментом разработки и не требуется обычному пользователю уже собранного приложения.

### Создание EXE-файла

Перейдите в корневую папку проекта, где находится `main.py`, и выполните:

```bash
pyinstaller --noconfirm --onefile --windowed --name KeyboardTyper main.py
```

Описание параметров команды:

| Параметр | Назначение |
|---|---|
| `--noconfirm` | Перезаписывает существующие результаты сборки без дополнительных вопросов |
| `--onefile` | Создаёт один исполняемый файл |
| `--windowed` | Запускает приложение без отображения консольного окна |
| `--name KeyboardTyper` | Задаёт имя итогового EXE-файла |
| `main.py` | Указывает точку входа приложения |

PyInstaller автоматически анализирует импорты и включает необходимые модули Python и зависимости в сборку.

### Результат сборки

После успешной сборки в корневой папке появится следующая структура:

```text
KeyboardTyper/
│
├── build/                  # Временные файлы сборки
│
├── dist/
│   └── KeyboardTyper.exe   # Готовое приложение
│
├── env/
│
├── main.py
├── app.py
├── typing_engine.py
├── config.py
│
├── requirements.txt
├── README.md
│
└── KeyboardTyper.spec
```

Готовый исполняемый файл находится по пути:

```text
dist/KeyboardTyper.exe
```

Его можно запускать двойным щелчком мыши.

Благодаря параметру `--onefile` для запуска собранной версии достаточно одного EXE-файла. На компьютере пользователя не требуется отдельно устанавливать Python, Tkinter или pynput.

При переносе EXE-файла на другой компьютер учитывайте, что программа предназначена для Windows.

### Повторная сборка

При изменении исходного кода достаточно повторно выполнить команду сборки:

```bash
pyinstaller --clean --noconfirm --onefile --windowed --name KeyboardTyper main.py
```

Параметр `--clean` очищает кэш предыдущих сборок.

Рекомендуется проверять результат именно из папки `dist`, поскольку запуск исходного кода и запуск собранного EXE могут вести себя по-разному.

### Сборка с консолью для отладки

Если при запуске EXE возникают ошибки, можно временно собрать приложение с отображением консольного окна:

```bash
pyinstaller --noconfirm --onefile --console --name KeyboardTyper main.py
```

В этом режиме сообщения об ошибках Python будут отображаться в консоли.

Для обычного использования рекомендуется вернуться к параметру `--windowed`.

## Особенности и ограничения

### Поддержка раскладок

В текущей реализации предусмотрено переключение между двумя раскладками:

- Русская (RU).
- Английская (EN).

Для переключения используется сочетание клавиш `Alt + Shift`.

Убедитесь, что именно это сочетание настроено в параметрах Windows для переключения языков ввода.

Все символы, не относящиеся к русскому алфавиту, обрабатываются как английские. Поэтому цифры, знаки препинания и специальные символы вводятся с расчётом на английскую раскладку.

Точка обрабатывается отдельным способом с использованием виртуального кода клавиши `VK 190`.

### Работа с целевым окном

Перед началом печати необходимо самостоятельно переключиться на нужное приложение и установить курсор в соответствующее поле.

После начала ввода программа отправляет клавиатурные события в активное окно. Поэтому не следует переключаться на другие приложения во время печати: текст может начать вводиться не в то место.

### Скорость печати

Фактическая скорость ввода зависит от производительности компьютера, обрабатывающего приложения и установленной задержки.

Нулевое значение задержки не гарантирует мгновенный ввод текста: сама обработка клавиатурных событий также занимает время.

Для больших объёмов текста рекомендуется предварительно проверить подходящую скорость на небольшом фрагменте.

### Безопасность

Не используйте приложение для ввода паролей, платёжных данных и другой конфиденциальной информации в ненадёжные приложения.

Программа имитирует ввод с клавиатуры и не проверяет, какое именно окно в данный момент находится в фокусе.

## Устранение неполадок

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'pynput'` | Активируйте виртуальное окружение и выполните `pip install -r requirements.txt`. |
| `ModuleNotFoundError: No module named 'tkinter'` | Проверьте установку Python. Для Windows используйте официальный установщик Python с компонентом Tcl/Tk. |
| Приложение не запускается из VS Code | Убедитесь, что выбран правильный интерпретатор Python и активировано виртуальное окружение. |
| Русские символы вводятся некорректно | Проверьте наличие русской раскладки и настройку переключения через `Alt + Shift`. |
| Раскладка не переключается автоматически | Проверьте, что сочетание `Alt + Shift` назначено в настройках Windows и что установлены русская и английская раскладки. |
| Символы вводятся не в то окно | Перед окончанием обратного отсчёта переключитесь на нужное приложение и установите курсор в поле ввода. |
| В EXE возникает ошибка, но консоль не отображается | Выполните сборку с параметром `--console` и изучите сообщение об ошибке. |
| `pyinstaller` не является внутренней или внешней командой | Установите PyInstaller в активированное окружение: `pip install pyinstaller`. При необходимости запустите его через `python -m PyInstaller`. |
| EXE не запускается на другом компьютере | Убедитесь, что используется поддерживаемая версия Windows, и проверьте файл через сборку с параметром `--console`. |
| Ввод обрывается или происходит слишком медленно | Уменьшите или увеличьте задержку в настройках приложения, проверив подходящее значение. |
